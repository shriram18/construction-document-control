# Construction Document Control — Professional Edition

A professional starter web app for construction document control.

## Modules
- Dashboard
- Projects
- Document Register
- Shop Drawings
- RFI
- MIR
- WIR
- NCR
- Material Submittals
- Transmittals
- MOM
- Revision history
- Due dates / overdue
- Search and filtering
- CSV/Excel-friendly export
- Role-ready navigation

## Run
This starter is a browser-based prototype. Open `index.html` directly for a demo.
For production deployment, connect the UI to a managed database/authentication and file storage (e.g. Netlify-compatible services).

## Suggested production stack
Frontend: React/Next.js
Hosting: Netlify
Database: PostgreSQL
File storage: object/blob storage
Authentication: role-based authentication
Audit: immutable activity log
